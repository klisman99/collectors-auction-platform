# Triage labels

This repository intentionally does not use triage-state labels.

Do not create or apply `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, or `wontfix`. An issue is ready for autonomous implementation only when its body contains complete acceptance criteria, references the relevant business rules, and identifies all blocking issues.

Milestones and dependency references communicate execution state. Existing repository labels may still be used for non-triage classification if the maintainer introduces them later.
