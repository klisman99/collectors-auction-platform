# Issue tracker

Implementation work for this repository is tracked in GitHub Issues:

- Repository: `klisman99/collectors-auction-platform`
- Tracker: `https://github.com/klisman99/collectors-auction-platform/issues`

Publish work as thin vertical slices that include the relevant persistence, backend, public contract, UI, and tests. Each issue must contain acceptance criteria and explicit blockers. Publish blockers first so later issues can reference real issue numbers.

Use GitHub milestones M1 through M6 to reflect `docs/roadmap/milestones.md`. Do not create a separate issue tracker under `.scratch/`.
